Fundamento

Três regras. Tudo aqui sai delas.

Padrão visual não é lista de cores: é um conjunto pequeno de decisões que resolvem os casos que ainda não aconteceram. Estas são as três.

1
Sequência à vista

Número, etapa e ordem são elementos de design, não enfeite. Onde existe processo, ele aparece numerado — e a etapa atual se distingue à distância.

2
A letra é a marca

A identidade não está na cor: está na tipografia. Serifada com itálico para a voz, sem serifa para a informação. Prova disso: imprima em preto e branco — continua sendo nosso.

3
Ouro é consequência

O dourado não decora: marca o que importa — a etapa atual, o resultado, a ação principal. Um ouro por tela. Se tudo é dourado, nada é.

FaçaUma ação dourada por tela. O resto em tinta ou linha. O olho vai direto ao que decide.
Não façaTrês botões dourados lado a lado. Vira feira, e o cliente não sabe onde clicar.
Identidade

A marca é um operador.

O selo carrega a exclamação — o símbolo de fatorial. Ele nunca é deformado, nunca troca de cor e nunca aparece sobre foto sem contraste.

Cor

Pouca cor, muito contraste.

Cada valor abaixo foi medido contra o papel. Nenhuma cor de texto entra no padrão abaixo de 4,5:1 — não por norma, mas porque texto que não se lê custa cliente. Clique para copiar.

Superfície
Tinta · contraste medido sobre o papel
Ouro · dois papéis que não se misturam

O erro clássico é usar o dourado de superfície como cor de texto: #d4af5e sobre branco = 2,0:1 — ilegível. Para ler, use --ouro-txt.

Sinal · uma cor, um significado

Verde é sempre concluído. Ouro é sempre “é com você”. Laranja é sempre atraso. Vermelho é sempre bloqueio. Nunca troque o significado — a pessoa aprende a cor uma vez e confia nela para sempre.

Tipografia

Duas famílias, papéis separados.

Fraunces tem eixo óptico: em corpo grande afina e ganha ar, em corpo pequeno engrossa e continua legível. É a voz. Inter é a informação — ela some, e é para sumir.

Espaço

A escala é multiplicada, não somada.

Não é 8, 16, 24, 32. Cada degrau é o anterior vezes cerca de 1,5 — a mesma lógica do fatorial. Isso cria hierarquia sem precisar pensar: dois blocos com espaços vizinhos parecem irmãos; com espaços distantes, parecem seções diferentes.

Regra prática: dentro de um componente use até --e-4. Entre componentes, --e-5. Entre seções, --e-9. Nunca invente um valor fora da escala.

Peça

Botão

Três pesos, e a hierarquia é visível a três metros de distância.

Ouro = o que faz a coisa acontecer. Tinta = ação firme sem ser a principal (entrar, confirmar). Linha = alternativa, voltar, cancelar. Bloqueada nunca some: fica visível com o motivo no title, senão a pessoa acha que quebrou.

Peça

Superfície

Cartão

Branco sobre papel. É o padrão para agrupar informação.

Recuado

Papel-2 para o que está em repouso ou é secundário.

Recorte escuro

Grafite para o que precisa parar o olho: prova, login, chamada.

Sombra é distância, não enfeite. Dois níveis só: --sombra para cartão que levanta no hover, --sombra-alta para o que flutua de verdade.

Peça

Selo de estado

É o componente mais repetido do sistema inteiro. Por isso o significado é fixo.

✓ concluído ◐ é com você ⚠ 8h de atraso ✕ bloqueado R$ 12.400 rascunho

Sempre com ícone e texto. Cor sozinha não comunica para quem não distingue verde de laranja — e não comunica em papel preto e branco.

Toda sequência do grupo usa esta forma: esteira comercial, processo de execução, jornada do cliente, etapas de um serviço. Numerada, com o que passou em verde e a etapa atual em ouro.

A etapa atual sempre traz de quem é a bola e o prazo. Trilha sem dono é enfeite — vira decoração de processo, que é o oposto do que a marca defende.

Peça

Campo

Entra na qualificação das partes do contrato.
Todo campo de dinheiro se separa sozinho enquanto você digita.

Todo campo tem rótulo visível — nunca só placeholder, que some quando a pessoa começa a escrever. E quando o campo decide alguma coisa, ele explica embaixo o porquê.

Número sozinho não informa: sempre com rótulo (o que é) e pé (de onde veio). “94%” não quer dizer nada; “94% no prazo, de 43 itens” quer.

Conduta

Movimento

Uma curva só e três durações. Animação que chama atenção para si mesma é ruído — aqui ela só confirma que a interface respondeu.

--rap · 180ms

Resposta ao toque: hover, foco, botão.

--med · 280ms

Mudança de estado: abrir, trocar, revelar.

--len · 720ms

Entrada em cena, ao rolar a página.

Quem configurou o sistema operacional para reduzir movimento não vê animação nenhuma — está no padrão, não é opcional.

Conduta

Voz

O jeito de escrever é parte da identidade tanto quanto a cor. Quatro regras.

Diga o porquê, sempre

Toda trava, todo campo obrigatório e toda etapa explicam a razão de existir. Regra sem motivo vira burocracia — e burocracia se contorna.

Frase curta, palavra comum

“Quanto falta” em vez de “gap de atingimento”. Quem lê é dono de empresa, não consultor.

Número em vez de adjetivo

“Payback de 22 meses, dentro do atrativo” vale mais que “excelente retorno”. Adjetivo é opinião; número é argumento.

Nunca prometa o que não mostra

Se está escrito no site, tem que existir na tela. É a diferença entre a nossa empresa e uma promessa bonita.

“A empresa é o reflexo do dono.”
Carla Caroline — a frase que resume o método. Use com parcimônia: frase repetida perde força.
Prática

Como usar

Em qualquer página nova
<link rel="stylesheet" href="a-fatorial.css">
<link href="https://fonts.googleapis.com/css2?family=Fraunces:ital,opsz,wght@0,9..144,300..600;1,9..144,300..500&family=Inter:wght@300..700&display=swap" rel="stylesheet">

Depois é só usar os tokens: var(--ouro-txt), var(--e-5), var(--t-26). Nunca escreva um valor cru no CSS — se o valor não existe na escala, ou você achou um caso novo (e ele entra aqui), ou está resolvendo errado.

Onde este padrão vale
Já usa

O site (porta de entrada do cliente) e este guia. Os dois carregam o mesmo arquivo — é por isso que são o mesmo lugar.

Usa a mesma régua

O sistema interno segue as mesmas decisões — papel claro, ouro de texto separado do ouro de superfície, trilha numerada, selo com significado fixo.
