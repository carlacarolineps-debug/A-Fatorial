# Convenções de trabalho — A! Fatorial / Operação Blindada

## Entrega de arquivos (regra da Carla)

1. **Sempre que finalizar uma tarefa, enviar os HTML resultantes como anexo** na
   conversa (SendUserFile), não apenas commitar.
2. **Nome dos arquivos entregues:** `NOME_DDMM.VV.html`
   - `DDMM` = dia e mês da entrega no fuso de Brasília (ex.: 20/07 → `2007`)
   - `VV` = versão do dia, começando em `01` (ex.: `VENDAS_2007.01.html`;
     segunda revisão no mesmo dia → `VENDAS_2007.02.html`)
3. **Organizar as entregas numa pasta com o nome do projeto** (ex.:
   `OPERAÇÃO BLINDADA/`) e enviar os arquivos a partir dela.
4. Os arquivos canônicos do repositório mantêm os nomes técnicos
   (`vendas.html`, `portal.html`, `estrategia.html`, `index.html`) porque há
   links relativos entre eles (ex.: `PORTAL_URL='./portal.html'`). As cópias
   versionadas são geradas na hora da entrega.

## Mapa do projeto

- `vendas.html` — página de vendas da mentoria (oferta 12× R$ 397, 21 vagas)
- `portal.html` — portal do mentoreado (inclui módulo Padrão de Gestão Blindada)
- `estrategia.html` — playbook estratégico interno (confidencial)
- `index.html` — sistema de gestão interno da A! Fatorial

(`#f4c150`/`#d4a340`/`#b98a2c`), prata/aço (`#c8cfd7`), tipografia serifada de
peso (Playfair/Fraunces) + mono para etiquetas. Não alterar o logo.
