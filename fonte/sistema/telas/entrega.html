Uma entrega por vez

Onde a entrega é escrita, e o que falta para ela ficar pronta.

Cada uma das oito responde uma pergunta diferente, e por isso os campos mudam de uma para a outra: aqui não existe formulário igual para tudo. O roteiro foi copiado de Roteiros e níveis no dia em que o projeto nasceu e não muda mais, para o combinado de um contrato não mudar no meio. O cliente só vê a entrega depois do envio para validação, e o envio publica o retrato dele no mesmo gesto.
